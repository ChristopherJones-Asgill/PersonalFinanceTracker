# Personal Finance Tracker

Personal Finance Tracker is a Java application for keeping track of income and expenses. Users can add transactions, view their current balance, and see spending by category.

## Features

- Add income and expense transactions
- View all saved transactions
- Track total income, expenses, and balance
- View spending by category
- Delete transactions
- Saves data using a CSV file
- JavaFX graphical interface

## Technologies

- Java
- JavaFX
- Maven
- CSS
- CSV file storage

## Run the Project

Requires Java 21 and Maven.

```bash
mvn javafx:run
```

To run the console version:

```bash
mvn compile exec:java
```
